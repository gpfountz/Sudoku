# Security Policy

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting for this repository. Open the
[Security page](https://github.com/gpfountz/Sudoku/security), select **Advisories**, then
**Report a vulnerability**. See GitHub's
[private reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)
for details.

If the reporting button is unavailable, open an issue asking the maintainer to enable private
reporting. Do not include vulnerability details in that issue or in a public Pull Request.

Include the affected commit or app version, macOS and Python versions, reproduction steps,
expected and actual behavior, and the likely impact. Use synthetic data; do not send passwords,
private keys, or personal saved games. Coordinate any public disclosure with the maintainer.

Ordinary bugs and feature requests can use public repository issues.

## Supported versions

Security fixes are maintained on the current `main` branch. Older development snapshots and
locally built app copies do not have separate maintenance branches; reproduce against current
source when practical and include the original affected version in your report.
